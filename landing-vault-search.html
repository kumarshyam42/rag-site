Features

Built for how you actually use Obsidian

No external apps. No browser tabs. Search your vault with AI, right where you work.

🧠

Semantic Understanding

Search by concept, question, or idea. Vault Search understands meaning, not just string matching.

⚡

Instant Indexing

Indexes your vault on first run. Incrementally updates as you edit. No manual re-indexing needed.

🔑

Bring Your Own Key

Uses your own API key for embeddings (OpenAI or Voyage AI). Your data never touches our servers.

🎮

Command Palette Native

Trigger with Cmd+Shift+S or from the command palette. Results link directly to the note and line.

🗃

Folder & Tag Filters

Scope your search to specific folders, tags, or note types. Combine semantic + structured filtering.

📦

Local-First Storage

Vector index stored right in your vault's .obsidian folder. No cloud dependency. Works offline after indexing.

Works everywhere Obsidian does

Desktop only for now. Mobile support coming soon.
